    SEE IT RUNNING

    It started as a real operations map.

    This grew out of a production system for a multi-site flight school, shown here on anonymized data. Several live sources drive one map at once:

    • Punch-clock attendance places every employee by role.
    • Scheduling and dispatch decide which lessons are running.
    • Live ADS-B radar shows which aircraft are actually flying.
    • GPS-tracked vehicles appear in the lot when they arrive.
    • A replay scrubs back through the whole day.
